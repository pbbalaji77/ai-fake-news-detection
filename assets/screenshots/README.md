# Application Portfolio Screenshots

This directory stores high-resolution visual screenshots of the **AI-Powered Fake News Detection System** for use in documentation, GitHub README, and LinkedIn portfolio showcases.

### Recommended Portfolio Screenshots:
1. `home_screen.png`: Main landing page with article input area, sample loaders, and sidebar metadata.
2. `real_prediction.png`: Credibility result card for authentic journalistic news (green card, confidence score, text statistics, and authentic indicator keywords).
3. `fake_prediction.png`: Credibility result card for fabricated news (red card, confidence score, sensationalism index, and misleading indicator keywords).
4. `model_comparison.png`: Performance bar chart comparing Accuracy, Precision, Recall, and F1 across candidate architectures.
5. `confusion_matrices.png`: Side-by-side heatmaps of confusion matrices for Logistic Regression, Naive Bayes, and Linear SVM.
6. `eda_distributions.png`: Dataset class balance and word count spread histograms from the EDA tab.

### How to Capture:
1. Run `streamlit run app.py` locally.
2. Click **"Load REAL News Sample"** $\rightarrow$ **"Analyze News"** and capture the full-width result.
3. Click **"Load FAKE News Sample"** $\rightarrow$ **"Analyze News"** and capture the sensationalism and explainability breakdown.
4. Navigate to the **"Model Benchmarks & Comparison"** and **"Exploratory Data Analysis"** tabs to capture the evaluation visualizations.
5. Save screenshots into this directory with the filenames listed above.
